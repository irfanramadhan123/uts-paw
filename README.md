## Fitur
1. pada beranda menampilkan ada berapa portofolio dan ada berapa kategori
2. pada koleksi dapat melihat list atau card dari semua portofolio yang ada dan melakukan search
3. pada tambah dapat menambahkan portofolio dengan memasukkan judul,kategori,Teknologi,tahun serta tautan,
4. pada statistik dapat melihat masing masing kategori memiliki berapa portofolio dan melihat jumlah keseluruhan 
5. pada tentang untuk melihat identitas saya,tema serta source code
6. page tidak ditemukan untuk menangkap error ketika path tidak seusai atau path tidak ada
